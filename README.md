# Website PPDB Online — Ma'had Al-Iktisyaf Cirebon
*(Sub Ma'had Al-Shighor Pondok Pesantren Gedongan)*

Website profil dan pendaftaran santri baru (PPDB / PSB) modern berarsitektur **Multi-Halaman (*Multi-Page Navigation*)** persis seperti sistem **shighor.com**.

---

Situs web ini telah dibagi ke dalam halaman-halaman mandiri agar rapi, fokus, dan tidak bertumpuk di satu halaman:

Buka folder **`d:\web ppdb`** di laptop Anda:
* Klik dua kali file **`index.html`** untuk mulai dari Beranda.
* Klik menu di bagian atas (Profil, Pendidikan, Fasilitas, Biaya & Syarat, Daftar Sekarang) untuk berpindah halaman secara mulus!
